# Análise da Base de Dados **Cuisine Rating**

Este repositório contém um código em Python para exploração inicial da base de dados **Cuisine Rating**. O objetivo é realizar uma análise exploratória simples, identificando padrões e estatísticas relacionadas às classificações de restaurantes, localizações, orçamentos e outros aspectos.

## Funcionalidades do Código

1. **Carregamento dos Dados**:  
   Os dados são carregados a partir de um arquivo CSV chamado `Cuisine_rating.csv` usando o pandas.

2. **Exploração Inicial**:  
   - Visualização das primeiras linhas do conjunto de dados com `head()`.
   - Exibição de informações gerais, como tipos de dados e valores nulos, com `info()`.

3. **Análise de Localizações**:  
   - Listagem das localizações disponíveis na base.
   - Contagem de ocorrências para cada localização.

4. **Filtragem de Dados**:  
   - Identificação de restaurantes com classificação geral máxima (5.0).  
   - Cálculo da média do orçamento para restaurantes com classificação máxima.
